# The Huang File

An independent editorial news-site prototype focused on Jensen Huang, NVIDIA, and the people and institutions around the AI buildout.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

```powershell
start index.html
```

## Pages

- `index.html` — homepage and lead briefing
- `article.html?id=transition` — main resignation story
- `article.html?id=investigation` — investigation explainer
- `article.html?id=leadership` — Colette Kress profile
- `article.html?id=market` — market analysis
- `article.html?id=history` — founder-era retrospective
- `timeline.html` — visual timeline
- `archive.html` — searchable archive with desk filters
- `about.html` — publishing method and corrections policy

## Built with

Plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Editorial boundaries

The site clearly separates confirmed facts, attributed allegations, and unresolved questions. It is an editorial prototype, not an affiliation of NVIDIA or Jensen Huang. Source links and photo credits are included in the relevant pages.
